## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se ejecutan con `php <archivo>.php`. Los proyectos tipo librería separan `src/` y `test/`, declaran PHPUnit en su `composer.json`, configuran el runner con `phpunit.xml` y se prueban con `composer test` (equivalente a `vendor/bin/phpunit`).

**EN:** Standalone scripts run with `php <file>.php`. Library-style projects separate `src/` and `test/`, declare PHPUnit in their `composer.json`, configure the runner with `phpunit.xml`, and are tested with `composer test` (equivalent to `vendor/bin/phpunit`).
